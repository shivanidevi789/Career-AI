# 🎓 Career AI - AI Powered Career Guidance Platform

Career AI is an intelligent AI-powered career guidance platform developed using the MERN Stack and OpenRouter API integration. The platform helps users discover suitable career paths, generate personalized learning roadmaps, and receive AI-based career guidance through an interactive chatbot system. 🚀

---

## ✨ Features

✅ User Registration and Login System  
✅ Interest-Based Career Assessment  
✅ AI Career Recommendation Engine  
✅ Personalized Learning Roadmaps  
✅ AI Chatbot Integration  
✅ Career Match Analysis  
✅ User History Management  
✅ Responsive Modern UI  
✅ Dark Mode Support  
✅ Interactive Career Guidance

## 🚀 Setup Instructions

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/shivanidevi789/Career-AI.git

cd Career-AI
```

---

### 2️⃣ Install Dependencies

#### Frontend

```bash
cd client
npm install
```

#### Backend

```bash
cd server
npm install
```

---

### 3️⃣ Setup Environment Variables

Create a `.env` file inside the server folder:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
OPENROUTER_API_KEY=your_api_key
```

---

### 4️⃣ Run the Project

#### Start Backend

```bash
npx nodemon server.js
```

#### Start Frontend

```bash
npm start
```

## 📊 System Workflow

1. User registers/login into the platform
2. User selects interests
3. User answers aptitude questions
4. AI analyzes responses
5. Career recommendations are generated
6. Personalized roadmap is displayed
7. User interacts with AI chatbot for guidance
